## Truth chain verified

* Instrument/Master references are now produced by the **unmodified**
  `core/libs/NewDisplay/{bar,label,list,frame,bgLabel,displayControls}.cpp`
  compiled into `fwref_core` on the host.
* Layout/style/text expressions come from `native/tools/fwref/specs/*.json`,
  generated by `extract_spec.py` from `gInstrEdit.cpp`, `gMasterParams.cpp`,
  `titleBar.cpp` and `Themes.cpp`, each carrying a line range + SHA-256.
* `fwref::runOracleSelfTest()` asserts the unmodified `cBar` contract:
  background `#0A0A0A`, container `#080808`, white 75px fill starting at
  y=224 for value 50, no green in the workspace.
* `render/fwref/instrument_params.png` and `render/fwref/master_page1.png`
  are the only references used by `os_input_runner.py` for those screens.

## Deviations from the plan text (code is authoritative)

1. **Self-test container sample.** The plan samples `(12,41)` for `#080808`,
   but `cBar` paints an 8px black→container gradient at `x=11..18` over the
   container. The gate samples `(40,41)`; `(12,41)` is `#010101`.
2. **Full-screen background sample.** `(2,30)` is covered by the 1.5px frame's
   top edge (y=30..31), so the background contract samples `(50,35)`.
3. **Master scenario alignment.** `DemoSong` set `masterGainDb = -3.5` while
   the plan's scenario is firmware volume 81 (0.00 dB). `DemoSong` now uses the
   firmware default 0 dB so the app state matches `scenario.json`; the app maps
   dB → volume with `round((dB+51.5)/63.5*100)` and the 81→0.00 dB special case.
4. **Header chrome.** The firmware reference intentionally contains only the
   title bar (title + optional right label); `songTimer` is not part of the
   contract. The app therefore suppresses the transport timer for these two
   screens and right-aligns the instrument label at x=790 (firmware
   `titleBar.cpp` RightX). Other screens keep the existing header.
5. **Master saturation frame.** `cList::setValue()` does not move `barPos`, so
   the frame remains on row 0; reproduced deliberately.
6. **Headless audio clock.** `NullAudioBackend` now pumps the engine callback
   at real-time pace (silent). `--remote`/screenshot runs previously never
   advanced the playhead, which made `pattern_transport` fail structurally;
   functional smoke is now 17/17.
7. **Line rasterisation.** Firmware widths are 1/16px; the host reference rounds
   `24 → 2px`, the app draws the same frame with `AddRect(1.5px)`. This is the
   remaining documented sub-pixel difference.
