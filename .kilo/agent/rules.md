# Trakr Native Rules

## Edit Scope
- **Allowed**: Only files in `native/` directory
- **Forbidden**: `core/`, `platforms/`, `synth/`, `util/` directories

## Visual Parity Requirements
- All 8 screens must achieve ≥95.0% pixel similarity
- Current status: 94.38% average (3/8 screens completed)
- Never regress visual similarity
- Use FT812 reference coordinates for exact pixel alignment

## Brand Guidelines
- No "hardware" or "Polyend" in user-facing UI
- Brand references only in About/Credits if needed
- No Renoise-style UI elements unless device has no equivalent
